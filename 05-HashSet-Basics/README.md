# ⚡ HashSet Basics & Set Operations

This project demonstrates the core concepts of `HashSet<T>` in C#, focusing on unique element storage, fast lookups, and set manipulation.

---

### 🇬🇧 Features & Concepts Covered
- **Unique Storage:** Prevents duplicate items automatically.
- **Element Manipulation:** Demonstration of `Add()` and `Remove()` methods.
- **ASCII Character Generation:** Programmatically populating an alphabet list using integer-to-char conversion.
- **Set Operations:** Utilizing `UnionWith`, `IntersectWith`, `ExceptWith`, and `SymmetricExceptWith`.

---

### 🇹🇷 Öne Çıkan Özellikler
- **Benzersiz Veri:** `HashSet` yapısı ile tekrarlayan elemanların önüne geçilmesi.
- **Eleman Yönetimi:** `Add()` ile eleman ekleme ve `Remove()` ile hatalı veriyi temizleme.
- **ASCII Alfabe Üretimi:** 97-122 ASCII kodları kullanılarak alfabe listesinin oluşturulması.
- **Küme Operasyonları:** `UnionWith` gibi dâhili metotlarla küme birleşimi uygulanması.
