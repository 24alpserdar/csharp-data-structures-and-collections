# 🚀 C# Data Structures & Collections

This repository contains practical implementations and hands-on examples of **Data Structures and Collections** in C# / .NET. 

The goal of this repository is to build a solid foundation in backend engineering, algorithm optimization, and software architecture.

---

## 🛠️ Tech Stack & Concepts Covered
* **Language:** C#
* **Framework:** .NET / Console Applications
* **Core Topics:** Lists, Queues, Stacks, Sets, Hash Tables, and Dictionaries

---

## 📂 Repository Content

* 🔹 **[ListAndReferenceTypes](./ListAndReferenceTypes):** Memory management, value vs reference types, and dynamic array operations.
* 🔹 **[LinkedListBasics](./LinkedListBasics):** Node structure, sequential memory access, and custom linked list operations.
* 🔹 **[StackDigitSeparator](./StackDigitSeparator):** LIFO (Last In, First Out) principle used for number manipulation and digit processing.
* 🔹 **[QueueInteractiveVowels](./QueueInteractiveVowels):** FIFO (First In, First Out) data processing with real-time user input.
* 🔹 **[HashtableSlugGenerator](./HashtableSlugGenerator):** Key-Value mapping and dynamic URL slug generation.
* 🔹 **[DictionaryPersonnelApp](./DictionaryPersonnelApp):** Generic Key-Value mapping for personnel registration and lookups ($O(1)$ complexity).
* 🔹 **[SortedListBookIndex](./SortedListBookIndex):** Key-based automatic sorting for book index systems.
* 🔹 **[SortedDictionaryBookIndex](./SortedDictionaryBookIndex):** Balanced tree structure for logarithmic lookups ($O(\log N)$).
* 🔹 **[SortedSetUniqueRandom](./SortedSetUniqueRandom):** Self-sorting unique collection with binary search tree functionality.
* 🔹 **[04-SortedSet-Set-Operations](./04-SortedSet-Set-Operations):** Set Theory operations (`UnionWith`, `IntersectWith`, `SymmetricExceptWith`).
* 🔹 **[05-HashSet-Basics](./05-HashSet-Basics):** High-performance unique storage and character manipulation with `HashSet<T>`.
